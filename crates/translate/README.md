# ultrafast-translate

Provider format translation for the Ultrafast AI gateway: request building,
response parsing, error classification and stream decoding for OpenAI-,
Anthropic- and Gemini-style APIs. No networking. It is the code the gateway and
the Rust, Python and TypeScript clients share.

Most users want [`ultrafast-client`](https://crates.io/crates/ultrafast-client)
instead. Published from v2.0.0-beta.4.
