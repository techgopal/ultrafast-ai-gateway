# Ultrafast 2.1.1

A small follow-up to 2.1.0.

## Changes

- **The MCP catalog has an address.** The signed catalog is published at
  `https://mcp.ufaigw.com/mcp-catalog/v1.json` (with the signature at `.sig`), and the
  gateway fetches it from there by default. 2.1.0 pointed at a name that did not
  resolve yet; those gateways used the catalog built into the binary and keep working.
  Set `UF_MCP_CATALOG_URL` to use a mirror, or `UF_MCP_CATALOG=off` to make no request.

## Upgrading

Replace the binary or image and restart. No migrations.
