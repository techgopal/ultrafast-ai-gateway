# Ultrafast 3.1.0

Claude Code and Codex work through the gateway: with a key, a route named after the model, and
the limits, budgets, guardrails and logs every other client gets. See "Coding agents" in the
README for the settings.

## What changes for you

- **Same family, passed through.** A `/v1/messages` call to an Anthropic provider and a
  `/v1/responses` call to an OpenAI or Azure provider reach the provider as the agent sent them,
  and the answer, stream or error comes back as the provider sent it. The response cache does
  not apply to these calls and a prompt template is refused on them (400). Calls to another
  family are translated, as before; what the target cannot express is dropped and named in the
  log row.
- **Logs and cost.** Rows record the agent's session and client and the tokens read from and
  written to the prompt cache. Models have cache read and write prices (empty: the input
  price). Rate limits, budgets, metrics and the usage API count cache reads and writes as
  input.
- **Guardrails.** Redaction on a coding agent's input rewrites the prompt, which costs
  prompt-cache hits (and Claude Code drops earlier thinking). Prefer Block or Flag there.
- **Console.** Logs filter by agent session and link to a session view with totals; the price
  dialog edits the cache prices.

## Upgrading

One additive migration (SQLite 0025, PostgreSQL 0011) runs at start. Replace the binary or use
`ghcr.io/techgopal/ufaigw:3.1.0`. The admin SDKs and `openapi/admin.json` gain the new log and
model fields; existing fields are unchanged.
