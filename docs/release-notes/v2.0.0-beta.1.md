# Ultrafast 2.0.0-beta.1

The first public release of Ultrafast v2. It is a beta: it is feature complete
for phase 1 and tested, but the admin API and the configuration may still
change before 2.0.0, so pin the version.

## What Ultrafast is

Ultrafast is one small Rust binary that sits between your apps and your LLM
providers. It speaks the OpenAI and Anthropic APIs, adds an admin API, and
serves a built-in web console, with SQLite for storage and nothing else to
run. It is for small teams who host it themselves.

## Highlights

- **One endpoint for many providers.** `/v1/chat/completions`, `/v1/messages`
  (Anthropic format), `/v1/embeddings` and `/v1/models`, with streaming, over
  OpenAI, Anthropic, Gemini, Azure OpenAI and any OpenAI-compatible API (Groq,
  Mistral, OpenRouter, Ollama and others). Provider credentials are encrypted
  at rest.
- **Routing and resilience.** Weighted targets, ordered fallbacks, retries,
  timeouts, circuit breakers and an exact-match response cache.
- **Access control.** Email and password sign-in, roles, teams, virtual keys
  with expiry and allowlists, a model catalog with grants, and an audit log.
- **Usage, limits and budgets.** Request logs (metadata only; no prompt or
  answer is stored), usage and spend reports, rate limits and budgets (block
  or alert).
- **A console in the binary.** Overview, logs, playground, providers, models,
  routing, keys, users, teams, limits and settings, in light and dark themes.
- **Operations.** Online backup, configuration export and import, Prometheus
  metrics, and an OpenAPI description of the admin API.
- **Clients** for Rust, Python and TypeScript sharing one Rust core.

The full list is in the [CHANGELOG](../../CHANGELOG.md).

## Install

Download the archive for your platform from the assets of this release (Linux
x86_64 and aarch64, macOS x86_64 and arm64, Windows x64), check it against
`SHA256SUMS`, unpack it and run:

```bash
UF_DATA_DIR=./data UF_ADMIN_EMAIL=you@example.com UF_ADMIN_PASSWORD='a long password' \
  ./ultrafast serve
```

Or use Docker (linux/amd64):

```bash
docker run -p 3000:3000 -v ultrafast-data:/var/lib/ultrafast \
  -e UF_ADMIN_EMAIL=you@example.com -e UF_ADMIN_PASSWORD='a long password' \
  ghcr.io/techgopal/ultrafast-ai-gateway:2.0.0-beta.1
```

The `latest` tag is for stable releases only, so a beta is reached by its
version tag.

## Quickstart

The [README](../../README.md#quickstart) walks from the first sign-in to the

## Upgrading from v1

v2 is a different codebase. Install it fresh: there is no data migration and
no compatibility with v1 configuration. v1 stays available at the tag
`v1-final`. If you ran `2.0.0-alpha.1`, back up first and see the README for
what changed.

## Known limits

- Rate limits, budgets, the response cache and routing health live in the
  memory of one process: one gateway per database.
- A `block` budget can be overshot by a short while; a stream that failed
  midway is charged an estimate.
- A configuration import never deletes; a backup restore is manual.
- Text chat only (no tools or images), and SQLite only.
- The image is for linux/amd64 only, and the crates are not on crates.io.

The README's "Known limits" section has the details.
