# Ultrafast 2.0.0-beta.2

The second beta of Ultrafast v2: tool calling and image input, a response
cache that no longer sends a stampede to the provider, and both in the
playground and the clients. It is still a beta, so pin the version.

## Highlights

- **Tools.** `tools`, `tool_choice` and `parallel_tool_calls` on
  `/v1/chat/completions` and `/v1/messages`, for every provider kind, streaming
  and not. Arguments pass through unchanged between OpenAI-format callers and
  providers, and are converted from or to the provider's JSON object otherwise.
  With no tools, `tool_choice` `auto` / `none` and `parallel_tool_calls` are
  ignored; `required` or a named tool is a 400, as is a named tool that is not
  in `tools`. `function.strict` is sent to OpenAI and Azure.
- **Images.** PNG, JPEG, GIF and WebP in user messages, as `http(s)` or `data:`
  URLs. The gateway never fetches an image URL. Gemini takes `data:` URLs only.
  Images count toward the 10 MiB request body limit (413 above it).
- **Single-flight cache.** Concurrent identical cacheable calls reach the
  provider once; waiters hold their concurrency slot, and if the first call
  fails they call the provider themselves. New metric
  `uf_cache_flight_waits_total`.
- **Playground.** Attach images, write tools as JSON, pick a tool choice, see
  tool calls and send results back.
- **Clients.** Tools and images in the Rust, Python and TypeScript clients.

The full list is in the [CHANGELOG](../../CHANGELOG.md).

## Install

As for beta.1: archives on the release assets (check `SHA256SUMS`), or Docker
(linux/amd64):

```bash
docker run -p 3000:3000 -v ultrafast-data:/var/lib/ultrafast \
  -e UF_ADMIN_EMAIL=you@example.com -e UF_ADMIN_PASSWORD='a long password' \
  ghcr.io/techgopal/ultrafast-ai-gateway:2.0.0-beta.2
```

The `latest` tag is for stable releases only; reach a beta by its version tag.

## Upgrading from beta.1

Stop, replace the binary or image, start; back up first. No configuration
change is needed.

## Known limits

- No Responses API, image or audio output, or `response_format` / structured
  outputs yet (phase 2).
- Gemini thought signatures are not carried; earlier tool calls are sent with
  Google's documented placeholder (`skip_thought_signature_validator`). Gemini
  tool call ids are `call_<8 hex>_<n>`, different for every answer.
- A tool result's `is_error` flag is not carried.
- `function.strict` reaches OpenAI and Azure only.
- Single-flight is per process, and a waiting caller keeps its concurrency slot.
  Changing configuration still clears the whole response cache.
- Wheels, the npm package and the crates are not published.

The README's "Known limits" section has the details.

## What's next (phase 2)
