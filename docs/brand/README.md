# Brand

The mark is a gate: two pillars, and a bolt passing straight through — a request through the gateway, fast.

| File | Use |
|---|---|
| `mark.svg` | The mark alone (64-unit grid). |
| `logo.svg` / `logo-dark.svg` | Mark and wordmark, for light and dark grounds. |
| `banner.png` | GitHub social preview (1280×640): Settings › Social preview. |
| `../../ui/public/favicon.svg` | Browser tab icon; pillars widened for 16 px; inverts in dark tabs. |
| `../../ui/public/apple-touch-icon.png`, `icon-512.png` | Home-screen and app icons. |

Colours: ink `#121417`, paper `#F6F5F1`, signal red `#E11D48`. Type: Space Grotesk (wordmark), JetBrains Mono (code).
